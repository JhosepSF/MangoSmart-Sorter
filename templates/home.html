¿Cómo funciona el flujo de trabajo?
  1. Crea un lote arriba o selecciona uno que ya esté configurado.
  2. Abre la interfaz de cámara en un teléfono celular montado sobre la caja de iluminación.
  3. Abre el dashboard de supervisión en esta computadora.
  4. Conecta los dispositivos a través del mismo código de lote.
  5. El sensor de Arduino detectará el mango, enviará la señal para capturar la foto, el backend clasificará con ConvNeXt-Tiny y enviará la orden serial para separar el mango.
